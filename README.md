# MS4000

A replacement for Microsoft Mouse and Keyboard center to use your trusted
*MS Natural Ergonimic 4000 keyboard*.

Written in C, without any bells and whistles.

## Motivation
Having two windows services running just to use the special keys on the 4000
also seemed overkill to me. At first, I thought about using AutoHotKey for 
creating a replacement. There were a lot of examples to find on the web, but
AHK is really cumbersome to use when working with win32-DLL-calls and binary data.
